Reffi

냉장고 속 재료가 버려지기 전에, 오늘 먹게 만든다

색은 신선도, 정렬은 마감 임박 순. 따뜻한 크림 종이 위 파스텔 색 블로킹과 지갑형 카드 스택으로 말하는 시스템 — 보더·이모지·색박스 없이. 이 페이지 자체가 그 규칙으로 만들어졌다.

Appetizing Clear Action-first
01

디자인 원칙

전역 규칙: 보더 금지 · 이모지 금지 · 색박스 금지 · 색 단독 의미 금지. 순백 배경·순흑 텍스트·네온도 쓰지 않는다. 그림자는 떠 있는 요소와 카드 스택에서만.

색 = 신선도

색은 장식이 아니라 정보다. 남은 날짜를 신선(Fresh)→곧(Soon)→오늘(Urgent)으로 직결하되, 항상 텍스트 라벨을 함께 둔다.

파스텔로, 화사하게

신선도 색은 부드럽고 밝은 파스텔. 네온·완전 채도를 피하고, 칙칙해지지 않도록 명도를 높게 유지한다.

카드 스택이 기본 레이아웃

재료 리스트는 지갑형 카드 스택 하나로 통일한다. 두 번째 레이아웃 시스템(벤토 그리드 등)을 섞지 않는다.

메인을 기본값으로

모든 브랜드 색은 main/dark/light 3종이지만 평소엔 main만. 일반 액션·정보·AI는 신선도와 무관한 Blue로 분리한다.

02

모든 색은 OKLCH. 신선도 3색(Sage·Amber·Terracotta)을 파스텔로 보정해 가져오고 Lilac은 제외, 네 번째는 Reffi Blue(레시피·AI·기본 액션). 각각 main / dark / light. 컬러 스킴은 현재 라이트 고정(preferredColorScheme(.light)) — 다크 토큰 램프가 정의되기 전까지 고정 크림 팔레트와 적응형 머티리얼(글래스)이 다크에서 어긋나는 중간 상태를 막는다.

06

엘리베이션 & 보더

보더는 기본 금지(예외: 포커스 링). 그림자도 기본 금지 — 떠 있는 요소(모달·드롭다운·토스트·바텀시트)와 카드 스택에만. 투명도는 10% 이하, 이중 그림자.

인터랙션 & 모션

상태 피드백은 분명하되 모션은 짧고 절제되게. transform·opacity만 애니메이트하고 transition: all은 금지.

버튼 — hover · active · focus · disabled

마우스를 올리면 main→dark, 누르면 scale(0.97). Tab으로 포커스하면 Blue 포커스 링. (hover는 포인터 가드 안에서만) "오늘 먹기"는 긴급 액션이라 Urgent, 일반 액션·AI는 Blue.

10

적용 체크리스트

화면을 내보내기 전 확인.

  • 신선도 색이 카운트다운과 일치하고, 색 + 라벨을 함께 썼는가
  • 파스텔 면 위 글자는 ink, Blue 면 위 글자는 white인가
  • 파스텔 카드 경계를 색이 아니라 스택 그림자·여백으로 만들었는가
  • 화면 내 타이포 위계 ≤ 3, 브랜드 색 ≤ 3인가
  • Display=Story Script(영문)/Pretendard(한글), 그 외 GSF(영문)/Pretendard(한글)인가
  • 데이터성 숫자에 .num(tabular)을 적용했는가
  • 모든 텍스트가 word-break:keep-all + orphan 방지를 따르는가
  • 아이콘이 SVG이고 색으로 채운 아이콘 박스가 없는가
  • 인터랙티브 요소가 hover·active·focus·disabled를 모두 갖고, hover에 포인터 가드가 있는가
  • 터치 타깃이 44×44(권장 48) 이상, 간격 ≥8px인가
  • prefers-reduced-motion을 존중하고 transition:all을 쓰지 않았는가
  • 보더·이모지·순백배경·순흑텍스트·네온을 쓰지 않았는가 · 1200px 분기로 함께 전환되는가
  • (행동 표면) 종이컷 셰이프에 완벽한 원·사각·캡슐을 쓰지 않고, 종이 헤어라인을 분리 보더로 오용하지 않았는가 (§13)
  • 통통 스프링을 행동 표면에만 쓰고 정보 표면(카드 스택)엔 남용하지 않았는가 · 추천 캐러셀에 네비 없이 닫기(X)가 있는가 (§7.5/§13)
11

종이 · 글래스 · 모션 — MD §13

메인 플로우의 행동 표면(재료·버튼·티켓)에 입히는 한 겹: 손으로 자른 종이 + 리퀴드글래스 + 일러스트 실루엣 + 통통 튀는 모션. 정보 표면(§02~§09)의 규율은 그대로 둔다.

종이컷 아이콘 버튼 (Tossed · Ate)

손으로 자른 종이 9각형 + 가운데 채운 아이콘 + 아래 라벨. 솔리드(Blue/흰 아이콘) · 소프트 틴트(blush/terracotta). 통통 프레스.

인텐트 6종 — primary · soft · fresh · soon · urgent · neutral

와이드 CTA · 종이 버튼 (8각형)

모서리 잘린 길쭉한 8각형 + 솔리드 색 + 종이 질감(그라데이션·아이콘 없음) + 통통 프레스(scale 0.96).

재료 뱃지

캡슐이 아닌 종이 둥근 사각 + 좌측 인디케이터 바(신선도색) + 이름. 탭으로 끄기, 점선 ＋로 추가.

연두부 D-0 애호박 D-2 당근 D-5 레몬 D-7 ＋ 추가

리퀴드글래스 네비

색면 위를 떠 있는 캡슐 네비만 글래스 머티리얼(블러+투과). 버튼은 색을 살리고 시노만.

일러스트 · 물리 낙하

재료는 각진 면분할(faceted) 컷페이퍼 일러스트(곡선 대신 5~9각 직선 면 + 몸통 2~3톤 면분할 + 오프컬러 액센트[양파 뿌리 보라], `FoodGlyph` 52종 — 채소·과일·고기·생선·유제품·곡류·저장식품)로, 진짜 물리 엔진으로 묵직하게 떨어져 쌓이고 그대로 남는다(끌어서 던지기). 충돌체는 각 글리프 실측 알파 bbox 기반 볼록 폴리곤(bbox의 ~90% + 시각 중심 정렬)이라 겹침·지터 없이 안착한다. 일러스트는 자연색이라 신선도는 뱃지로(§2.5 행동표면 예외) — 씬 위에 이름 라벨을 얹지 않는다. 카테고리 라벨은 기존 8종에 Grain(곡류)·Pantry(저장식품)를 더한 10종이며, v2 신규 17종(가지·고구마·생강·김·포도·수박·파인애플·망고·소시지·베이컨·게·오징어·조개·요거트·버터·꿀·만두)은 전부 이 기존 라벨로 편입한다(신규 라벨 없음). 칩을 드래그하면 판정 바스켓(마그네틱) — 좌상 휴지통(Tossed)·우상 냄비(Ate) 종이 블롭이 나타나고, 반경 ≈88pt에 들면 재료가 자석처럼 끌려 들어가(1.14× 확대) 놓는 즉시 확정된다(되돌리기 토스트가 안전망). 배경은 리퀴드글래스.

오더 메모 카드 (추천 캐러셀)

주방 오더 티켓: 상·하 톱니 절취 + 모노 헤더 + 점선 룰 + 판정문 키커 + 메뉴/시간 + 재료 체크리스트(최대 5줄 + N more) + PREP 조리 메모(최대 3단계 미리보기 + N more, 전체 단계는 발주 후 단계별 조리 화면이 정본) + "이걸로 요리" 발주 CTA(발주 시 START 스탬프 슬램). 덱은 풀스크린·네비 없음 — 뒤에 겹친 종이가 실제 다음 티켓이며(가장 깊은 티켓만 머리 렌더 — 바로 뒤는 풀 렌더라 플릭 승격이 매끄럽다), 맨 앞을 튕겨(플릭) 넘긴다(순환). 카드는 화면 높이에 캡되고 중간 섹션은 필요 시 카드 안에서 스크롤(큰 글씨 안전망). 발주 = 예약(START 슬램은 연출, 재고 차감·이력은 요리 완료에서 확정 — 재료별 "다 썼어요/조금 남았어요" 원탭, 조리 취소는 예약 해제). 발주는 커버당 1회 + 6초 되돌리기 → 곧장 단계별 조리 화면(체크리스트), 메인의 Cooking now 카드로 복귀. 판정 커버엔 urgent 한정 Freeze 3번째 선택지 — 얼리면 유예 14일의 새 D-day(재냉동 불가), 냉장고 카드엔 FROZEN 도장. 발주 덱은 시드·커스텀·AI 생성 티켓이 한 덱 — AI 생성 레시피는 별도 트레이 없이 "#NN" 왼쪽 sparkle + AI 미니 배지로만 구분한다. 캐러셀이 열리면 재고 기준으로 생성을 트리거해, 끝나는 대로 아직 덱에 없는 AI 티켓을 최대 2장 뒤에 조용히 이어붙인다(기존 카드 순서·정체성 불변, 진행 중엔 상단에 작은 힌트, 실패해도 문구 없이 사라짐).

입력 시트도 행동표면 언어를 따른다 — 재료 추가는 폼이 아니라 픽커다. 타이핑으로 임의 재료를 만드는 직접 입력 폼은 주 추가 플로우에 없다 — 일러스트 사전 픽커 + 영수증 스캔이 전부. 크림 캔버스 + 흰 영수증 카드(스캔 카드) + 검색 필드(사전 필터, 임의 생성용 아님) + 픽커 그리드(PaperSilhouette 일러스트 + 흰 종이 타일, 3~4열 — FREQUENT 이력/시드 → 카테고리 섹션)로 짓는다. 탭 = 즉시 추가(사전 기본값으로 폼 없이 저장) — 일러스트는 카테고리를 대표할 뿐 고른 재료와 1:1이 아니다, 정확한 표기는 하단 피드백 스트립("Added {name} · {n} this run" + Edit)이 책임진다. 검색이 사전에서 못 찾을 때만 컴팩트 커스텀 시트(이름 고정 + 기한·수량·보관)로 폴백한다 — 사전 밖 재료를 만드는 유일한 경로. 커스텀·편집 시트는 여전히 모노 섹션 라벨(ITEM·DETAILS · OPTIONAL) + DashedRule + PaperButton 문법. 시스템 글래스 툴바·리퀴드글래스 배경 금지(입력 표면은 조용한 종이) — 상단은 종이 X 닫기 헤더. 쇼핑리스트 재입고는 시트조차 열지 않고 이력 스냅샷 + 사전 기본 기한으로 곧장 채운다.
냉장고 요약·정렬도 §13 문법을 공유한다. 헤더 아래 요약 페이저(장보기 · 무낭비 리포트, 한 장씩 스와이프)는 PaperCutRect 종이컷 버튼 면 + 옅은 그레인 + 점 인디케이터로 짓는다. 정렬 메뉴 칩과 간편보기 원탭 토글은 둘 다 PaperRect 종이 면(히트 44pt), 간편보기 행은 틸트·겹침 없는 납작한 흰 영수증 한 조각 — 실루엣 + 이름 + 수량 + D-day(냉동이면 + FROZEN 도장)를 한 줄로 훑어보기에 최적화한다.
경계. 이 레이어는 메인·캐러셀의 행동 표면에 한정한다. 냉장고 목록·카드 스택(§08)·일반 정보 화면은 §02~§09 규율(파스텔 색-블로킹·보더 금지·평소 그림자 금지)을 그대로 따른다.
